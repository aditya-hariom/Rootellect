## Technical Stack
- **Framework:** Next.js (App Router, React 19 / TypeScript)
- **Styling:** Tailwind CSS
- **Database & ORM:** PostgreSQL + Prisma
- **State Management:** Zustand / React Context with LocalStorage
- **Testing:** Playwright (E2E & calculation checks)
